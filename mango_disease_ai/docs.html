⚡ 8-Step Quick Start

From zero to fully running API — step by step. Works on Windows, Mac, Linux. No local folder needed.

1
Open PowerShell / Terminal
Easy ▼

Press Windows Key → type PowerShell → press Enter.
On Mac/Linux: open Terminal.

✅ You will see
PS C:\Users\YourName> _
2
Install the Package
~1 min ▼

Copy and paste this command → press Enter. This installs the AI library + API server tools.

PowerShell
PS> pip install "mango-disease-ai[api]"
✅ You will see at the end
Successfully installed mango-disease-ai-0.1.3
3
Verify Installation
5 seconds ▼

Check that the package is installed correctly by printing the version number.

PowerShell
PS> python -c "import mango_disease_ai; print(mango_disease_ai.__version__)"
✅ You will see
0.1.3
4
Start the API Server
First run: 2-3 min ▼

Run this single command from any folder — no need to navigate anywhere. The server starts on port 8000.

PowerShell
PS> mango-api
# Custom port (optional)
PS> mango-api --port 8080
# Alternative (also works)
PS> python -m mango_disease_ai.server
✅ You will see
============================================================
🥭 Mango Disease AI -- REST API Server v0.1.3
============================================================
Starting on http://0.0.0.0:8000
Welcome page http://localhost:8000
Swagger UI http://localhost:8000/docs
Full Docs http://localhost:8000/guide
Press CTRL+C to stop.
⚠️ First run only: CLIP model (~600 MB) downloads automatically. Wait 2-3 minutes. All future runs start instantly.

import requests
# Health check
r = requests.get("http://localhost:8000/api/health")
print(r.json()) # {"status":"ok","version":"0.1.3"}
# Analyze image
with open("mango.jpg", "rb") as f:
  r = requests.post("http://localhost:8000/api/analyze",
    files={"image": f}, data={"include_gradcam": "false"})
result = r.json()
print(result["predicted_class"], result["confidence"])
# Download PDF
with open("mango.jpg", "rb") as f:
  r = requests.post("http://localhost:8000/api/report",
    files={"image": f}, data={"user_name": "Dr. Rahman"})
open("report.pdf", "wb").write(r.content)
app.js
async function analyzeMango(imageFile) {
  const formData = new FormData();
  formData.append("image", imageFile);
  formData.append("include_gradcam", "false");
  const res = await fetch("http://localhost:8000/api/analyze",
    { method: "POST", body: formData });
  if (res.status === 422) { alert("Not a mango!"); return; }
  const result = await res.json();
  console.log(result.predicted_class, result.confidence);
  document.getElementById("heatmap").src =
    "data:image/png;base64," + result.gradcam_base64;
}

All Endpoints

5 API Endpoints

GET/api/health~10ms
Server alive check. Returns OK + version.
{"status": "ok", "version": "0.1.3"}
GET/api/diseases~5ms
All 7 disease classes with scientific name, symptoms, remedies.
POST/api/analyze~2-8 sec
Upload mango image → full diagnosis JSON. Returns HTTP 422 if not a mango.
{"is_mango": true, "predicted_class": "Healthy", "confidence": 0.9470,
 "all_scores": [{...}, ...], "disease_info": {...}, "gradcam_base64": "..."}
POST/api/report~10-15 sec
Upload image + name → download PDF report. Body: image + user_name.
GET/guideThis Page
This animated documentation page — bundled inside the package.
